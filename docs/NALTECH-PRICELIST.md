# Pricelist Layanan Naltech Studio

Dokumen ini menjadi acuan internal saat membuat penawaran jasa website Naltech Studio. Harga di bawah adalah rekomendasi per Agustus 2026 dan dapat disesuaikan berdasarkan kompleksitas, jumlah halaman, kesiapan materi, integrasi, serta target waktu pengerjaan.

## Ringkasan harga publik

Harga yang disarankan untuk ditampilkan pada website atau materi promosi:

| Paket | Harga mulai | Cocok untuk |
| --- | ---: | --- |
| Landing Page | **Rp3.500.000** | UMKM, produk, jasa, promosi, atau event |
| Business Website + CMS | **Rp8.500.000** | Perusahaan yang ingin mengelola halaman dan artikel sendiri |
| Custom Website | **Rp15.000.000** | Website dengan fitur, database, integrasi, atau alur bisnis khusus |

Gunakan istilah **harga mulai** karena harga final harus mengikuti scope yang disepakati.

## 1. Landing Page

**Harga normal: Rp3.500.000**

**Harga promo portfolio: mulai Rp2.750.000**

Cocok untuk bisnis yang membutuhkan satu halaman dengan fokus pada promosi dan konversi.

### Termasuk

- Satu halaman hingga 8–10 section
- Desain custom mengikuti identitas bisnis
- Tampilan responsif desktop, tablet, dan mobile
- Tombol WhatsApp dan formulir kontak dasar
- SEO dasar dan metadata social sharing
- Setup Google Search Console
- Optimasi performa dasar
- Domain dan hosting satu tahun sesuai batas paket
- Maksimal tiga tahap revisi
- Estimasi pengerjaan 7–14 hari kerja

### Tidak termasuk

- Dashboard untuk mengubah konten
- Penulisan artikel rutin
- Foto produk atau produksi konten
- Sistem login, database, pembayaran, atau booking kompleks
- Biaya layanan pihak ketiga berbayar

## 2. Business Website + CMS

**Harga mulai: Rp8.500.000**

Cocok untuk perusahaan yang membutuhkan website lengkap serta kemampuan mengunggah artikel sendiri.

### Termasuk

- Hingga 5–7 halaman utama
- Landing page atau halaman beranda
- Halaman daftar artikel
- Halaman detail artikel
- CMS untuk mengelola konten
- Upload gambar dan artikel
- Draft dan publish
- Kategori dan penulis
- SEO title dan description untuk setiap artikel
- Sitemap artikel otomatis
- Training penggunaan CMS satu kali
- Domain dan hosting satu tahun sesuai batas paket
- Maksimal empat tahap revisi
- Estimasi pengerjaan 3–5 minggu

### Teknologi yang direkomendasikan

- Next.js untuk website
- Sanity sebagai CMS utama
- Struktur URL artikel: `/artikel` dan `/artikel/[slug]`
- Project CMS dan deployment dipisahkan untuk setiap klien

### Tidak termasuk

- Jasa penulisan artikel
- Upload artikel rutin setelah serah terima
- SEO bulanan atau jaminan peringkat Google
- Migrasi konten dalam jumlah besar
- Fitur membership, pembayaran, atau dashboard bisnis khusus

## 3. Custom Website

**Harga mulai: Rp15.000.000**

Harga final ditentukan setelah kebutuhan dan alur bisnis selesai dibahas.

### Contoh fitur

- Dashboard admin
- Login dan beberapa jenis pengguna
- Database
- Booking dan penjadwalan
- Katalog produk
- Payment gateway
- Membership
- Notifikasi email atau WhatsApp
- Integrasi API pihak ketiga
- Laporan dan export data
- Workflow internal

### Catatan penawaran

Jangan memberikan harga final sebelum membuat daftar fitur, batas pengerjaan, integrasi, dan tanggung jawab masing-masing pihak. Untuk project besar, pisahkan pekerjaan menjadi beberapa milestone.

## Maintenance dan biaya berulang

Biaya pembuatan harus dipisahkan dari biaya operasional serta maintenance.

| Layanan | Rekomendasi harga |
| --- | ---: |
| Domain dan hosting | Rp1.000.000–Rp2.000.000 per tahun |
| Maintenance landing page | Rp350.000 per bulan |
| Maintenance website CMS | Rp750.000 per bulan |
| Maintenance custom website | Mulai Rp1.500.000 per bulan |
| Pengelolaan dan upload artikel | Rp150.000–Rp300.000 per artikel |

Maintenance dapat mencakup:

- Monitoring website
- Backup berkala
- Update dependency dan patch keamanan
- Perbaikan error dalam scope
- Perubahan konten minor
- Dukungan teknis sesuai jam kerja

Permintaan fitur baru tidak termasuk maintenance dan harus dibuatkan estimasi terpisah.

## Ketentuan pembayaran yang disarankan

### Project kecil

- 50% uang muka sebelum pengerjaan
- 50% setelah website disetujui dan sebelum dipublikasikan

### Project custom

- 40% uang muka
- 30% setelah desain dan fitur utama disetujui
- 30% setelah pengujian dan sebelum serah terima

Pengerjaan dimulai setelah uang muka dan materi awal diterima.

## Aturan revisi

- Revisi berarti penyesuaian terhadap scope yang sudah disepakati.
- Perubahan konsep utama setelah desain disetujui bukan revisi biasa.
- Penambahan halaman, fitur, integrasi, atau alur baru dihitung sebagai pekerjaan tambahan.
- Setiap tahap revisi sebaiknya dikumpulkan menjadi satu daftar agar pengerjaan terarah.

## Checklist sebelum memberikan harga final

- Tujuan utama website
- Jumlah halaman
- Daftar fitur
- Referensi desain
- Kesiapan logo, foto, dan teks
- Kebutuhan CMS
- Jumlah bahasa
- Integrasi pihak ketiga
- Domain dan hosting
- Target waktu peluncuran
- Kebutuhan maintenance
- Penanggung jawab konten dari pihak klien
